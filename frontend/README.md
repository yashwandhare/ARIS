# IATS Frontend

Frontend for the intern analytics and training system.

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- React Router v6
- TanStack Query
- Recharts
- Lucide React

## Features

- Dashboard with candidate stats and filters
- Review room with accept/reject actions
- Candidate detail view with training plan generation
- Interns, analytics, and settings pages

## Run

```bash
npm install
npm run dev
```

Build with `npm run build` and preview with `npm run preview`.

## Notes

- Uses mock data by default
- Layout is responsive across desktop and tablet
- Production integration can swap mock data for API calls
